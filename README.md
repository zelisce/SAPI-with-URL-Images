# SAPI with URL images

This resource pack fixed the unusable URL images within Action forms when using Script API.

## How does it work?

It is actually pretty simple! It uses the newly discovered `profile_image_renderer` that allows resource packs to display URL images without the Action form button to explicitly be in the URL format, which Script API does not support.

## How do I use it?

All you need to do is add the resource pack in the [latest release](https://github.com/zelisce/SAPI-with-URL-Images/releases/latest), or use the source code to implement the renderer yourself! Just that simple! No need for external plugins or software.
